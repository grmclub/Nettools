Here are five highly practical  scripts to automate daily workflows, system administration, and file management. 

1. Automated Directory Backup
This script creates a compressed .tar.gz archive of a specified folder. It appends a precise timestamp to prevent overwriting old backups and automatically creates the target backup directory if it does not exist. 
bash

#!/bin/bash
# Backup a specific directory with a timestamp

SOURCE_DIR="/path/to/source_folder"
BACKUP_DIR="/path/to/backup_folder"
TIMESTAMP=$(date +%Y%m%d_%H%M%S)
BACKUP_NAME="backup_$TIMESTAMP.tar.gz"

# Create the backup folder if it missing
if [ ! -d "$BACKUP_DIR" ]; then
    mkdir -p "$BACKUP_DIR"
fi

# Compress and archive the source directory
tar -czf "$BACKUP_DIR/$BACKUP_NAME" "$SOURCE_DIR"

echo "Backup completed successfully: $BACKUP_DIR/$BACKUP_NAME"

2. Disk Space Monitor and Alert
This script monitors system storage. It checks all partitions and flags any drive exceeding a specified threshold percentage. You can easily connect this to an email client or webhook. 
bash

#!/bin/bash
# Alert when disk usage crosses the safety threshold

THRESHOLD=80

df -h | grep -vE '^Filesystem|tmpfs|cdrom' | awk '{ print $5 " " $1 }' | while read -r output;
do
    # Extract the numerical percentage value
    usage=$(echo "$output" | awk '{ print $1 }' | cut -d'%' -f1)
    partition=$(echo "$output" | awk '{ print $2 }')
    
    if [ "$usage" -ge "$THRESHOLD" ]; then
        echo "ALERT: Partition $partition is at ${usage}% capacity!"
    fi
done

3. Bulk File Renamer
This utility safely replaces spaces with underscores (_) for all files inside a chosen directory. It helps clean up files downloaded from the web or shared across different operating systems. 
bash

#!/bin/bash
# Replace spaces in filenames with underscores

TARGET_DIR="/path/to/target_directory"

cd "$TARGET_DIR" || exit

for file in *; do
    # Check if the file name contains spaces
    if [[ "$file" == *" "* ]]; then
        new_name=$(echo "$file" | tr ' ' '_')
        mv "$file" "$new_name"
        echo "Renamed: '$file' -> '$new_name'"
    fi
done

4. Website Availability Checker
This lightweight script uses curl to ping a web service. It checks the HTTP response code to ensure your site or API server is running smoothly. 
bash

#!/bin/bash
# Check if a website or local web app is up

URL="https://example.com"
STATUS_CODE=$(curl -s -o /dev/null -w "%{http_code}" "$URL")

if [ "$STATUS_CODE" -eq 200 ]; then
    echo "SUCCESS: $URL is up and running (Status: $STATUS_CODE)."
else
    echo "WARNING: $URL might be down! (Status: $STATUS_CODE)."
fi

5. Automated System Resource Cleanup
Over time, temporary systems, development builds, and old caches consume valuable storage. This script clears common temporary directories, standard system logs, and broken symlinks.
bash

#!/bin/bash
# Clean temporary files and broken system shortcuts

echo "Starting system cleanup..."

# Clear user cache files safely
rm -rf ~/.cache/*

# Find and delete broken symbolic links in the current workspace
find . -type l ! -exec test -e {} \; -delete

echo "Cleanup finished. System storage optimized."

2. Smart File Extractor (extract)

A unified script that automatically handles unpacking regardless of the archive format (.tar.gz, .zip, .rar, .tar.bz2, etc.).


#!/bin/bash
if [ -f "$1" ]; then
  case "$1" in
    *.tar.bz2)   tar xjf "$1"     ;;
    *.tar.gz)    tar xzf "$1"     ;;
    *.bz2)       bunzip2 "$1"     ;;
    *.rar)       unrar x "$1"     ;;
    *.gz)        gunzip "$1"      ;;
    *.tar)       tar xf "$1"      ;;
    *.tbz2)      tar xjf "$1"     ;;
    *.tgz)       tar xzf "$1"     ;;
    *.zip)       unzip "$1"       ;;
    *.Z)         uncompress "$1"  ;;
    *)           echo "'$1' cannot be extracted via extract()" ;;
  esac
else
  echo "'$1' is not a valid file"
fi

6. Random Secure Password Generator (genpass)

Generates a strong, random password on the fly without needing external tools.


#!/bin/bash
# Usage: ./genpass.sh [length, default 16]
length=${1:-16}
openssl rand -base64 48 | tr -dc 'a-zA-Z0-9_!@#$%^&*()' | head -c "$length"
echo ""

7. Local Network IP Scanner (netsweep)

Performs a fast ping sweep on your local subnet to see active devices.


#!/bin/bash
# Usage: ./netsweep.sh 192.168.1
subnet=${1:-192.168.1}
for ip in {1..254}; do
  ping -c 1 -W 1 "$subnet.$ip" >/dev/null 2>&1 && echo "Active: $subnet.$ip" &
done
wait

10. Bulk Lowercase Renamer (lowerify)

Converts all uppercase filenames in a directory to lowercase to prevent broken links or reference errors.


#!/bin/bash
for f in *; do
  if [ -f "$f" ]; then
    ext="${f##*.}"
    name="${f%.*}"
    newname="$(echo "$name" | tr '[:upper:]' '[:lower:]').$(echo "$ext" | tr '[:upper:]' '[:lower:]')"
    [ "$f" != "$newname" ] && mv "$f" "$newname"
  fi
done
