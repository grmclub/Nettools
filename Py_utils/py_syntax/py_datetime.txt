## 10 Essential Best Practices for Dates & Times in Python

    1. Always Store and Process in UTC
       Store all dates and times in UTC in database models and internal logic. Only convert to local timezones when displaying timestamps to end users.
    2. Avoid "Naive" Datetimes
       Always attach timezone information using zoneinfo (Python 3.9+) or pytz to make datetime objects "timezone-aware" and prevent silent errors during timezone shifts or Daylight Saving Time (DST).
    3. Use ISO 8601 Strings for Storage and APIs
       Format date/time strings as YYYY-MM-DDTHH:MM:SSZ using isoformat() and fromisoformat() for unambiguous parsing across different services and databases.
    4. Use timedelta for Simple Time Differences
       Perform operations like adding/subtracting days or hours using built-in datetime.timedelta objects rather than manually calculating seconds or days.
    5. Use dateutil.relativedelta for Complex Calendar Math
       For adding units like "1 month" or "1 year" (which vary in exact length), use dateutil.relativedelta instead of fixed-day timedelta arithmetic.
    6. Parse Arbitrary Strings with dateutil.parser or strptime
       Use datetime.strptime() for strict format validation, or dateutil.parser.parse() to automatically detect and parse unknown date formats.
    7. Leverage pandas.to_datetime for Bulk Data Processing
       When dealing with DataFrames or dataset series, use Pandas' vectorized functions (pd.to_datetime()) rather than iterating through lists with native Python standard libraries.
    8. Watch Out for Daylight Saving Time (DST) Transitions
       Never hardcode timezone offsets (e.g., assuming EST is always UTC-5). Always use named timezone identifiers like "America/New_York" via ZoneInfo.
    9. Use date.today() vs. datetime.now() Intentionally
       Use date.today() when time-of-day is irrelevant (e.g., birthdays or billing cycle dates) to avoid unnecessary timestamp precision overhead.
    10. Consider High-Level Modern Libraries (e.g., Pendulum or Arrow)
       For complex applications with heavy time calculations, third-party libraries like Pendulum or Arrow offer cleaner syntax for formatting, human-readable durations ("2 hours ago"), and timezone conversions.
